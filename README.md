# 🌍 World Happiness Index - Interactive Tableau Story

## 📌 Présentation du Projet
Ce projet explore les facteurs influençant l'indice de bonheur à travers le monde. L'objectif était de nettoyer le jeu de données brut, d'analyser les corrélations clés (notamment le soutien familial) et de construire une **Story interactive sur Tableau** intégrant du contenu web dynamique (Wikipedia API/Web Object).

## 🛠️ Outils & Technologies
- **Nettoyage & Préparation des données :** [Excel + Tableau]
- **Visualisation & Storytelling :** Tableau Desktop / Tableau Public
- **Intégration Web :** Tableau Web Page Actions (Wikipedia dynamic link)

---

## 💡 Visualisations & Insights Clés
1. **Distribution Géographique :** Cartographie de l'indice de bonheur moyen par région.
2. **Analyse de Correlation :** Relation positive marquée entre le *Family Score* et l'indice de bonheur global.
3. **Enrichissement Contextuel :** Action Tableau permettant d'afficher dynamiquement la page Wikipedia de la région sélectionnée.
